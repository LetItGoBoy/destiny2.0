6 帧猫咪逐帧动画

这个版本故意不用 CSS 平滑变形。每一帧都是一个离散姿势：尾巴换角度，眼睛换开合状态。 帧数越少越省资源，但动作会更“格子”；帧数更多会更顺。

frame: 1 / 6 tail: left, eyes: open

这里为什么叫逐帧？

因为它不是让一张图平滑旋转，而是定时切换“第 1 帧、第 2 帧、第 3 帧……”。 如果换成 PNG，就是每帧一张猫图；这里为了 demo 体积小，用 SVG 画出了 6 张姿势。

现在是最少可看的版本：尾巴只有左、中、右三个状态，眨眼只有开、半闭、闭三个状态。 真正上线可以把这 6 帧导成一张 sprite sheet。

150ms 
const frames = [姿势1, 姿势2, 姿势3...];
setInterval(() => {
  frame = (frame + 1) % frames.length;
  render(frames[frame]);
}, 150);
