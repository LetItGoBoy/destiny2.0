# 同乐八字 · 四柱八字排盘小程序

原生微信小程序，提供四柱八字排盘（真太阳时）、大运/流年/流月推演、八字记录云端存储等功能。

## 功能

- **八字排盘（首页）**：姓名、性别、公历/农历（含闰月）、出生时间、出生地（全国 34 省 392 市）、真太阳时开关
- **基础盘**：四柱八字、十神（主星）、藏干十神、星运（日干十二长生）、自坐、空亡、纳音、神煞、五行分布
- **详盘**：基础盘 + 大运、流年、流月；大运与流年均含十神、星运、自坐、神煞
- **记录**：八字可保存进记录，支持云端同步（微信云开发）或本地存储，长按删除
- **婚配 / 合作伙伴配**：首页入口，功能即将上线（占位页）
- **我的**：头像昵称、记录统计、联系方式、关于、切换用户、退出登录

## 排盘口径

| 项目 | 口径 |
| --- | --- |
| 干支/农历/节气 | [lunar-javascript](https://github.com/6tail/lunar-javascript) v1.7.7（已内置 `miniprogram/utils/lunar.js`，无需 npm 安装） |
| 晚子时（23:00–24:00） | 23 点换日，日柱算次日（流派 1，与主流排盘软件一致） |
| 年柱分界 | 立春 |
| 真太阳时 | 经度修正（每度 4 分钟）+ 均时差（近似公式，误差 ±20 秒内），见 `utils/solartime.js` |
| 神煞 | 自实现通行口径（天乙/太极/文昌/天德/月德贵人、禄神、羊刃、桃花、驿马、华盖、将星、劫煞、灾煞、亡神、孤辰寡宿、红鸾天喜、金舆、红艳、国印、魁罡、阴差阳错），见 `utils/shensha.js` |
| 城市经度 | QWeather China-City-List，精确到地级市驻地，见 `utils/cities.js` |

## 快速开始

1. 用 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 导入本仓库根目录；
2. 把 `project.config.json` 里的 `appid` 改成你自己的小程序 AppID（默认为游客模式 `touristappid`，可直接预览）；
3. 直接编译即可使用，八字记录默认存手机本地。

### 开通云端记录（可选）

1. 在开发者工具中开通「云开发」，记下环境 ID；
2. 在云开发控制台 → 数据库中创建集合 `bazi_records`，权限选「仅创建者可读写」；
3. 把环境 ID 填入 `miniprogram/config.js` 的 `cloudEnv` 字段。

配置后记录跟随微信账号跨设备同步；云端不可用时自动降级本地存储。

```
├── utils/
│   ├── lunar.js                     # lunar-javascript（第三方，勿改）

│   └── store.js                     # 记录存储（云端 + 本地降级）
└── pages/
    ├── index/                       # 首页：排盘表单 + 婚配/伙伴配入口
    ├── result/                      # 结果页：基础盘 / 详盘
    ├── records/                     # 记录
    ├── mine/                        # 我的
    └── match/                       # 婚配 / 合作伙伴配（占位）
```
